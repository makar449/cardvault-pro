# CardVault Dark Multipage

Многостраничная статическая версия премиального сайта по продаже коллекционных карт.

## Страницы
- index.html — главная
- catalog.html — каталог, поиск и фильтры
- product.html — карточка товара
- auctions.html — аукционы
- sell.html — форма продажи с превью фото
- authentication.html — проверка подлинности
- cart.html — корзина и оформление заявки
- favorites.html — избранное
- reviews.html — отзывы
- contact.html — контакты
- about.html — о проекте
- admin.html — локальная админка

## Важно
Это GitHub Pages-compatible версия. Корзина, избранное, заявки, админка и загрузка фото работают локально в браузере через localStorage. Для реальных платежей, аккаунтов и хранения данных на сервере нужен backend.
